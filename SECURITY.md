## Reporting a Vulnerability

We take the security of this project seriously. If you discover a cryptographic verification flaw, attestation spoofing vulnerability, or parsing bypass in the SBOM/SLSA engine, please report it responsibly:

1. **Do not create a public GitHub Issue.**
2. Email details to **gohilkosha19@gmail.com** with the subject `[SECURITY VULNERABILITY] Supply Chain Security & SBOM Attestation Mesh`.
3. Include:
   - Technical description of the bypass or integrity defect.
   - Sample payload (tampered attestation, malicious SBOM, or forged digest).
   - Impact assessment (e.g., SLSA Level 3 bypass, unverified binary promotion).

You will receive an initial response within 48 hours acknowledging receipt, followed by a remediation plan and disclosure timeline.
